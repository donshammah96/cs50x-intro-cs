## Working method

1. Watch or read the unit, and take notes in `notes/`.
2. Attempt every problem before checking any solution.
3. Commit each completed problem set with a descriptive message.
4. Write a short summary in `notes/` at the end of each unit.
5. Update the status badge and progress checklist at each milestone.
